代理模式说明：当目标 API 不支持 CORS 时，通过本地代理转发请求来绕过限制。

使用步骤：

  1. 在本地运行代理：node proxy.js（需要 Node.js）
  2. 勾选"代理模式"
  3. 代理地址默认 http://localhost:8888
  4. 正常输入目标 API 的 URL，请求会自动通过代理转发
